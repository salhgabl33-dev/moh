# هلا نت — بوابة الكروت 02.1

بوابة عربية لشبكة MikroTik تعمل برقم الكرت وحده بوصفه اسم المستخدم، دون حقل كلمة مرور. يختار كل عميل سرعته من أربع بطاقات واضحة قبل الدخول. التصميم بعمود واحد وعرض أقصى **448 بكسل** مثل حاوية الصفحة الأصلية، على الجوال والكمبيوتر، مع هوامش أصغر للشاشات الضيقة وخط Tajawal محلي ووضعين داكن وفاتح.

## ما تغيّر في هذه النسخة

- أُزيل حقل كلمة المرور وإظهارها، ولم يعد QR يقرأ كلمة مرور من الأكواد القديمة.
- رقم الكرت يرسل في `username` فقط. لا يُنسخ إلى `password`.
- في PAP يرسل `password` فارغاً؛ في CHAP تحسب الاستجابة باستخدام كلمة مرور فارغة ومعرّف وتحدّي الراوتر.
- استُبدلت الواجهة العريضة بصفحة هاتف متراصة، تعرض السرعات ثم رقم الكرت ثم زر الدخول، وتحتها الباقات ونقاط البيع والتعليمات والبث.
- اختيار السرعة يرسل **domain** بنفس صيغة النسخة الأصلية، وليس مجرد تغيير بصري.
- قارئ QR محلي مرفق لصور الكروت، يعمل دون CDN وبلا حاجة إلى BarcodeDetector؛ يستخدم القارئ المدمج عند توفره ويعود إلى jsQR عند غيابه.
- بقي اسم هلا نت، وأسعار الكروت والباقات، ونقاط البيع، وروابط البث وقيم السرعات من ملفك الأصلي.

## التركيب على MikroTik

1. فك `hala-net-v2.zip` واحتفظ بنسخة من مجلد hotspot الحالي وإعداد Hotspot Server Profile.
2. ارفع مجلد `hotspot` إلى Files باسم مستقل مثل `hotspot-v2`، بحيث يكون `login.html` داخله مباشرة.
3. في IP → Hotspot → Server Profiles افتح البروفايل المستخدم واضبط HTML Directory إلى المسار الفعلي للمجلد الجديد، وقد يبدأ بـ `flash/` حسب الجهاز.
4. أبقِ آلية مصادقة الشبكة الحالية. هذه البوابة مخصّصة للكروت ذات **اسم المستخدم فقط وكلمة المرور الفارغة** كما أوضحت. لا تغيّر كلمات مرور الحسابات أو إعدادات الراوتر لمجرد تركيب التصميم.
5. جرّب بكرت اختبار: السرعات الأربع، الدخول الصحيح والخاطئ، إعداد التحديثات، عرض الرصيد، البث، والخروج. اختبر هاتفاً صغيراً وهاتفاً كبيراً قبل التفعيل للجميع.
6. للرجوع أعد HTML Directory إلى المجلد السابق.

## تخصيص السرعات والإعدادات

عدّل `hotspot/portal-config.js` لتغيير الاسم والأخبار والباقات ونقاط البيع والسرعات وروابط البث. لا تغيّر `value` لكل سرعة إلا إذا غيّرت أيضاً إعدادات الشبكة التي تستقبل domain. قيمك الأصلية محفوظة:

| اختيار العميل | domain دون طلب منع التحديثات | domain مع الطلب |
| --- | --- | --- |
| اقتصادية | `1M/2M\|*no**` | `1M/2M\|*yes**` |
| متوسطة | `2M/4M\|*no**` | `2M/4M\|*yes**` |
| عالية | `4M/8M\|*no**` | `4M/8M\|*yes**` |
| فائقة | `8M/16M\|*no**` | `8M/16M\|*yes**` |

السرعة الافتراضية 2M/4M، ويُستعاد آخر اختيار محفوظ للعميل إن كان لا يزال متاحاً. للعميل حرية اختيار أي سرعة ظاهرة؛ لا ترتبط أزرار السرعة بباقة أو سعر جديد من عند الصفحة. تطبيق السرعات وحجب التحديثات الفعلي يعتمد على سكربتاتك أو RADIUS وإعدادات الشبكة. لتغيير السرعة أثناء جلسة متصلة يسجّل العميل الخروج ثم يختار سرعة أخرى ويدخل بكرته.

ملفات التصميم والبرمجة: `assets/portal.css` و`assets/portal.js` و`assets/chap.js`، والإعدادات في `portal-config.js`. الألوان في متغيرات CSS أول الملف. أبقِ أسماء صفحات MikroTik الأساسية كما هي: `login.html` و`status.html` و`logout.html` و`alogin.html` و`redirect.html` و`rlogin.html` و`error.html`.

## المعاينة

افتح `preview.html` الموجود بجانب الحزمة: ملف مستقل يحتوي الخطوط والتصميم والبرمجة وقارئ QR. يمكن أيضاً فتح `hotspot/preview.html` مع ملفات مجلده. المعاينة لا ترسل بيانات دخول ولا تحفظ رقم الكرت عند تجربة زر الدخول. على الراوتر تُستخدم `login.html` ومتغيرات MikroTik الحقيقية.

لا تستبدل استضافة الإنترنت بالراوتر لتشغيل الدخول؛ البوابة تحتاج أن يقدّم MikroTik الصفحات ويستبدل المتغيرات.

## حفظ الكروت وQR

- «محفظتي» تحفظ آخر خمسة كروت **بعد نجاح الدخول**، والأحدث أولاً. عند دخول كرت سادس يُحذف الأقدم، وإعادة استخدام كرت محفوظ تنقله للأعلى دون تكرار.
- الحفظ مفعّل افتراضياً ويمكن إيقافه. تظهر أرقام الكروت كاملة داخل المحفظة لاسترجاعها؛ لمس الكرت يعبئ حقل الرقم فقط دون إرسال دخول تلقائي. يتوفر حذف كرت منفرد أو إفراغ المحفظة.
- الأرقام محفوظة على المتصفح نفسه، وليست مزامنة بين الأجهزة. لا تُضاف المحاولات الخاطئة أو مجرد كتابة الرقم إلى المحفظة.
- **رقم الكرت هو بيانات الدخول بحد ذاته**؛ لا تحفظه على جهاز مشترك. إخفاء الرقم في صفحة الحساب ليس تشفيراً للتخزين المحلي.
- إذا كانت المحفظة الجديدة غير موجودة، تُنقل أسماء المستخدمين فقط من محفظة الصفحة الأصلية على المتصفح والعنوان نفسيهما، بحد خمسة أرقام والأحدث أولاً، دون نسخ كلمات مرور قديمة. لا تعاد استعادة محفظة أفرغها المستخدم. لإزالة جميع بيانات الصفحة السابقة احذف بيانات الموقع من المتصفح.
- يدعم QR رقماً نصياً أو رابطاً يحتوي `username` أو `card`، أو JSON يحتوي أحدهما. يتجاهل حقل `password` في أي كود؛ ولا يفتح الروابط المقروءة أو يسجّل الدخول تلقائياً.
- الصورة تُقرأ محلياً دون رفع. يمكن اختيار صورة أو التقاط صورة من خيارات الهاتف. يلزم دعم الصور وCanvas في المتصفح؛ الإدخال اليدوي متاح دائماً.
- البث المحلي يتطلب توفر الخادم والسماح بالوصول إليه على الشبكة. عنوانه محفوظ من ملفك الأصلي، ويمكن تغييره في الإعدادات.

## إعادة البناء والتحقق

ملفات الراوتر تعمل بلا Node أو Python. هذه الأدوات مطلوبة فقط على جهاز التطوير:

```sh
npm install
npm test
npm run package
```

أُرفق ترخيص jsQR في `hotspot/assets/jsqr-LICENSE.txt`. تفاصيل الاختبار وحدوده في `QA.md`. لم تُنفّذ سكربتات Python المرفقة في الحزمة الأصلية ولم تتغيّر إعدادات الراوتر.
