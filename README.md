# هلا نت · Hotspot 2027.3

بوابة عربية بتصميم زجاجي وألوان باستيل وشعار ذهبي، مع ملفات محلية للهوتسبوت وسكربتات CCR2116 / RouterOS 7.25 وUser Manager خارجي على RB1100x4 / RouterOS 6.

- افتح `hotspot/preview.html` لمعاينة تجريبية لا تنشئ اتصالاً بالإنترنت.
- افتح `hotspot/settings-2027.html` لتعديل الهوية والباقات وروابط الخدمات.
- اتبع [دليل رفع الصفحة والتراجع](README-AR.md)، ثم [دليل الدخول والخروج والتنقّل](routeros/README-AR.md).
- راجع [نتائج مطابقة التصدير الأصلي](routeros/ORIGINAL-AUDIT-AR.md) و[التحقق وحدوده](VALIDATION.md).

السرعات مطابقة الآن لبروفايل `hashedSpeed`: `1M/3M`، `2M/4M`، `2M/6M`، `5M/10M`، `10M/20M` بترتيب رفع/تنزيل. المتوسطة افتراضية، والخضراء «عالية جداً VIP» خامسة بعد عالية. الباقات والأسعار وكود محفظة شلن 20810 محفوظة.

تستخدم `hashedSpeed` و`default` و`UM10USER` كود دخول موحداً دون طرد تلقائي للجلسات أثناء التنقّل. إعدادات Cookie المقترحة 30 يوماً، وتبقى صلاحية الكرت وحصصه لدى User Manager. استمرار الاتصال بين نقاط الواي فاي يحتاج ثبات هوية الهاتف ومروره عبر خدمة الهوتسبوت نفسها؛ وجود عنوان ضمن رنج واحد وحده لا يضمن ذلك.

رفع مجلد `routeros/` إلى CCR يتيح تشغيل الإعداد المقيّد الموثق في الدليل:

```routeros
/import file-name=routeros/configure-roaming.rsc
```

يتحقق الملف من `hsprof1` الموجود والمفعّل لـRADIUS، ويحفظ نسخاً محلية خاصة من البروفايلات قبل التعديل. لا يغيّر DHCP أو VLAN أو `hsprof2` أو إعدادات User Manager، ولا يغيّر ربط مجموعة RADIUS.

لا تحتاج ملفات الراوتر إلى مكتبات. لتشغيل فحوص التطوير باستخدام Node.js 20.19 أو أحدث:

```sh
npm ci
npm test
```

الاختبارات البرمجية ومراجعة المصدر لا تثبت التنفيذ على RouterOS. جرّب حساباً واحداً والتنقّل والخروج وانتهاء الرصيد قبل التعميم، وراجع نتائج فحص المتصفح في `VALIDATION.md`.
