# هلا نت · Hotspot 2027

بوابة عربية جديدة مبنية على القالب الأصلي المرفق لشبكة هلا نت، بتصميم زجاجي بألوان باستيل وشعار ذهبي، مع ملفات محلية قابلة للرفع إلى MikroTik.

- افتح `hotspot/preview.html` لمعاينة التصميم ببيانات تجريبية.
- افتح `hotspot/settings-2027.html` لتعديل الاسم والباقات والخدمات وتنزيل ملف الإعدادات.
- اقرأ [دليل التركيب والتراجع](README-AR.md) قبل رفع مجلد `hotspot/` إلى الراوتر.
- راجع [تغييرات 2027](CHANGELOG-2027.md).
- لربط اختيار السرعة بالراوتر، راجع [سكربتات On Login وOn Logout للـCCR2116](routeros/README-AR.md)، مع User Manager خارجي على RB1100x4.

حافظ الإصدار على الباقات والأسعار والسرعات الأصلية وكود محفظة شلن. أصبحت السرعات خمساً بإضافة «عادية» `3M/6M`، وتأتي «عالية جداً VIP» الخضراء خامسة بعد «عالية». بقيت أسماء قوالب MikroTik الأساسية كما يحتاجها الراوتر.

لا تحتاج ملفات الراوتر إلى تثبيت أي مكتبات. لتشغيل فحوص التطوير فقط، استخدم Node.js 20.19 أو أحدث:

```sh
npm ci
npm test
```

نجاح الفحوص البرمجية لا يغني عن تجربة حساب اختبار على راوتر الشبكة. لم يُجر اختبار على MikroTik فعلي أو فحص بصري داخل متصفح في بيئة الإنشاء.
