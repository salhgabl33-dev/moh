# هلا نت — Portal 02

إعادة بناء لبوابة MikroTik المرفقة، بتصميم عربي كحلي ونعناعي، قابل للتكيف مع الهاتف والكمبيوتر، وخط Tajawal محلي. تحتفظ النسخة باسم هلا نت والباقات والأسعار ونقاط البيع وروابط البث وقيم السرعة من config.js الأصلي. لا تحتاج الصفحة إلى CDN أو اتصال خارجي لتحميل التصميم.

## التركيب

1. نزّل `hala-net-v2.zip` وفك الضغط على جهازك.
2. احتفظ بنسخة كاملة من مجلد hotspot الحالي وإعداد Hotspot Server Profile قبل الاستبدال.
3. ارفع مجلد `hotspot` الجديد إلى Files في MikroTik باسم مستقل مثل `hotspot-v2`. لا تضع مجلداً باسم hotspot داخل المجلد الذي سيختاره الراوتر.
4. في IP → Hotspot → Server Profiles، افتح البروفايل المستخدم واضبط HTML Directory إلى المسار الفعلي للمجلد الجديد (قد يبدأ بـ `flash/` حسب الجهاز). لا تغيّر آلية المصادقة أو قواعد الشبكة لمجرد تركيب التصميم.
5. جرّب بكرت اختبار وجهاز واحد أولاً: كلمة المرور الصحيحة والخاطئة، كل سرعة، طلب منع التحديثات، صفحة الرصيد، وتسجيل الخروج. تأكد أن اختيار domain يصل إلى سكربتاتك أو RADIUS كما في النسخة القديمة.
6. بعد نجاح التجربة فعّل المجلد لبقية المستخدمين. للرجوع أعد HTML Directory إلى المجلد السابق.

## التخصيص

عدّل `hotspot/portal-config.js` فقط لتغيير الاسم، الأخبار، الباقات والأسعار، السرعات، نقاط البيع، الإرشادات وروابط البث. لتغيير الهوية البصرية عدّل متغيرات الألوان في أول `hotspot/assets/portal.css`.

- ملفات التصميم والبرمجة الجديدة: `assets/portal.css` و`assets/portal.js` و`assets/chap.js` و`portal-config.js`.
- أبقِ أسماء MikroTik الأساسية `login.html` و`status.html` و`logout.html` و`alogin.html` و`redirect.html` و`rlogin.html` و`error.html`. تغييرها قد يعطّل مسارات الراوتر.
- الصفحة `index.html` توجّه إلى `login.html`، أما `preview.html` فهي معاينة مستقلة لا ترسل أي بيانات دخول.
- ملفّات Python وصفحات الإدارة والسكربتات القديمة غير مستخدمة في النسخة الجديدة. لم تُنفّذ تعليمات أو سكربتات الحزمة الأصلية.

## الوظائف والتوافق

- إرسال الدخول عبر POST الأصلي للراوتر، ودعم HTTP-CHAP عند توفير الراوتر `chap-id` و`chap-challenge`. خوارزمية MD5 مرفقة محلياً لهذا البروتوكول.
- `domain` يرسل مثلاً `2M/4M|*no**` أو `2M/4M|*yes**`، مطابقة للصيغة الأصلية. الصفحة لا تفرض السرعة ولا تمنع تحديثات الهاتف بنفسها؛ التطبيق يتوقف على تجهيز الشبكة. يتطلب البث المحلي توفر الخادم وصلاحيات الوصول أو walled garden المناسبة.
- عرض الحساب بمتغيرات MikroTik الأصلية. زر لتحديث الرصيد يدوياً، وخروج يمسح كوكي مصادقة الراوتر. لا تُختلق بيانات أو نسب متبقية عندما لا يرسل الراوتر حداً للباقة.
- حفظ ما يصل إلى خمسة أرقام كروت عند اختيار «تذكّر رقم كرتي»، دون حفظ كلمة المرور. الأرقام محفوظة محلياً ويمكن حذفها من الصفحة، ولا تُخفى عن مالك الجهاز الذي يقرأ التخزين المحلي. الإخفاء البصري في القائمة ليس تشفيراً.
- لا تُستورد كلمات المرور التي خزّنتها الصفحة القديمة؛ إن كنت تريد إزالة التخزين القديم فاحذف بيانات الموقع من المتصفح.
- QR من صورة، محلياً عبر BarcodeDetector حين يدعمه المتصفح والسياق الأمني. إن لم يتوفر يظهر بديل إدخال الرقم؛ لا وعد بدعم قارئ QR على كل متصفحات بوابات HTTP. يدعم كوداً نصياً لرقم الكرت، رابطاً يحوي username/password، أو JSON يحوي username/card وpassword. القراءة تعبئ البيانات فقط ولا تدخل تلقائياً.
- الأرقام العربية والفارسية في رقم الكرت تُحوّل إلى الإنجليزية وتُزال المسافات. كلمة المرور تبقى كما أدخلها المستخدم.
- وضع فاتح وداكن، تنقل لوحة مفاتيح، تسميات للحقول، ونوافذ يمكن إغلاقها بـ Escape.
- تغيير السرعة أثناء جلسة متصلة يتم بتسجيل الخروج ثم اختيار السرعة وتسجيل الدخول؛ لا تستخدم النسخة إعادة دخول صامتة بكلمة مرور فارغة.
- لم يُنسخ عارض الصور القديم: استُبدل بعنصر بصري محلي خفيف. روابط البث بقيت من الإعدادات الأصلية.

## المعاينة

افتح `hotspot/preview.html` من الملفات أو خادم محلي. هذه معاينة للتصميم فقط؛ الدخول والرصيد الحقيقيان يعملان عندما يقدّم MikroTik الصفحات ويستبدل المتغيرات. لا ترفع البوابة إلى استضافة عامة بدلاً من الراوتر وتتوقع عمل المصادقة.

## التحقق

راجع `QA.md` للاختبارات المنفذة والحدود. لم يتم الوصول إلى راوتر حي أو تعديل إعدادات الشبكة.
